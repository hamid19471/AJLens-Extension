# مجوزهای AJ Lens

AJ Lens کمترین مجوزهای لازم برای قابلیت‌هایش را درخواست می‌کند. این افزونه **هیچ host permission** و **هیچ content script خودکاری** در manifest ندارد.

مجوزهای تعریف‌شده در `public/manifest.json`:

</div>

```json
"permissions": ["activeTab", "scripting", "storage", "downloads"]
```

<div dir="rtl">

| مجوز        | استفاده در     | دلیل                                                                                                                                                                                                                                                     |
| ----------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `activeTab` | service worker | دسترسی موقت به تب فعلی، فقط پس از کلیک روی آیکون یا زدن میانبر (`_execute_action`). این دسترسی امکان تزریق `content.js` و فراخوانی `chrome.tabs.captureVisibleTab` را می‌دهد و با رفتن تب به صفحه دیگر پایان می‌یابد.                                    |
| `scripting` | service worker | فراخوانی `chrome.scripting.executeScript({ files: ['content.js'] })` برای تزریق بازرس، فقط در فریم اصلی و فقط هنگام درخواست شما.                                                                                                                         |
| `storage`   | content script | ذخیره تنظیمات رابط کاربری در `chrome.storage.local`. محتوای صفحه، تصویر یا پرامپت ذخیره نمی‌شود. [حریم خصوصی](PRIVACY.fa.md) را ببینید.                                                                                                                  |
| `downloads` | service worker | `chrome.downloads.download` برای ذخیره `reference.png`، `prompt.md` و `analysis.json` در `Downloads/AJ-Lens/<hostname>-<YYYY-MM-DD-HHmmss>/` با `saveAs: false` و `conflictAction: 'uniquify'`؛ و `chrome.downloads.show` برای دکمه «نمایش در دانلودها». |

## جزئیات مجوز `downloads`

- فقط service worker این API را فراخوانی می‌کند. پنل یک پیام اعتبارسنجی‌شده می‌فرستد.
- نام فایل برای هر نوع خروجی ثابت است و پوشه فقط می‌تواند به شکل `AJ-Lens/<یک بخش امن>` باشد.
- تصویر باید یک data URL از نوع PNG و تحلیل باید JSON معتبر باشد.
- هیچ راه جایگزینی برای دانلود از داخل صفحه وجود ندارد.
- این مجوز دسترسی به فهرست یا محتوای دانلودهای قبلی شما نمی‌دهد.

## مجوزهایی که عمداً درخواست نشده‌اند

| مجوز                               | چرا لازم نیست                                                                                                                            |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `tabs`                             | با `activeTab`، آدرس تب در لحظه کلیک در دسترس است و گرفتن تصویر هم مجاز است.                                                             |
| `<all_urls>` و host permissionها   | AJ Lens هرگز روی صفحه‌ای که خودتان فعالش نکرده‌اید اجرا نمی‌شود.                                                                         |
| `clipboardWrite`                   | کپی با `navigator.clipboard` در پاسخ به کلیک شما انجام می‌شود و در صورت شکست، از یک روش جایگزین با `execCommand('copy')` استفاده می‌شود. |
| `webRequest`، `cookies`، `history` | هیچ‌وقت لازم نیستند.                                                                                                                     |

## میانبر

فرمان `_execute_action` با کلید پیشنهادی <bdi dir="ltr">`Alt+Shift+S`</bdi> دقیقاً مانند کلیک روی آیکون عمل می‌کند و مجوز `activeTab` را هم فعال می‌کند. می‌توانید آن را در `chrome://extensions/shortcuts` تغییر دهید.
